# Java patterns

24 standalone loop and nested-loop exercises in the `Patterns` package.

Compile all exercises from the repository root with a JDK installed:

```sh
javac -d out Patterns/*.java
java -cp out Patterns.pattern1
```

Replace `pattern1` with `pattern2` through `pattern24` to run another exercise. Each program prints its pattern to standard output; no input is required. Class names match their source filenames so the entire collection compiles together.
